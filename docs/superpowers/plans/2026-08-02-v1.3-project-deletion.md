# Project OS v1.3 Project Deletion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an authorized, version-safe permanent project deletion flow that cascades project-owned data, preserves an audit record, and is usable from the glass project detail page.

**Architecture:** The contracts package defines the request/result boundary and audit operation. `ProjectService` owns authorization, default-project protection, version checks, child-count capture, audit creation, and transactional deletion. Express exposes the service through one DELETE route, while the Web repository/query layer removes stale cache data and a focused dialog enforces typed-name confirmation before navigation.

**Tech Stack:** TypeScript 6, Zod 4, Node SQLite, Express 5, React 19, TanStack Query 5, Vitest 4, Testing Library, Playwright.

- [ ] **Step 5: Implement authorization, counts, audit, and deletion**

Import `deleteProjectResultSchema`, `DeleteProjectResult`, and `ActorRole`. Change `assertActiveActor` to return `{ role, status }`. Add a focused permission helper and service method:

```ts
type ActorAccessRow = {
  role: ActorRole
  status: 'active' | 'inactive'
}

const PROJECT_CHILD_TABLES = [
  'project_members',
  'tasks',
  'requirements',
  'defects',
  'sessions',
  'handoffs',
  'deliverables',
] as const

function assertCanDeleteProject(
  actor: ActorAccessRow,
  actorId: string,
  project: PersistedProject,
): void {
  if (actor.role !== 'owner' && project.ownerId !== actorId) {
    throw new DomainError(
      'PROJECT_DELETE_FORBIDDEN',
      'Only a system owner or the project owner can delete this project',
      { actorId, projectId: project.id },
    )
  }
}

delete(
  id: string,
  expectedVersion: number,
  actorId: string,
  source: ActivitySource = 'web',
): DeleteProjectResult {
  const validatedSource = activitySourceSchema.parse(source)
  try {
    return withImmediateTransaction(this.database, () => {
      const current = this.get(id)
      if (id === 'project_default') {
        throw new DomainError(
          'DEFAULT_PROJECT_PROTECTED',
          'The default project cannot be deleted',
          { projectId: id },
        )
      }
      const actor = this.assertActiveActor(actorId)
      assertCanDeleteProject(actor, actorId, current)
      if (current.version !== expectedVersion) {
        throw new DomainError(
          'PROJECT_VERSION_CONFLICT',
          'Project version is stale',
          {
            projectId: id,
            expectedVersion,
            currentVersion: current.version,
          },
        )
      }

      const counts = Object.fromEntries(PROJECT_CHILD_TABLES.map((table) => [
        table,
        (this.database.prepare(
          `SELECT COUNT(*) AS count FROM ${table} WHERE project_id = ?`,
        ).get(id) as { count: number }).count,
      ]))
      const deletedAt = new Date().toISOString()
      recordActivity(this.database, {
        actorId,
        projectId: id,
        source: validatedSource,
        operation: 'project.delete',
        entityType: 'project',
        entityId: id,
        action: `Deleted project ${current.name}`,
        note: JSON.stringify({ projectId: id, projectName: current.name, counts }),
        createdAt: deletedAt,
      })
      const result = this.database.prepare(`
        DELETE FROM projects WHERE id = ? AND version = ?
      `).run(id, expectedVersion)
      if (Number(result.changes) !== 1) {
        throw new DomainError(
          'PROJECT_VERSION_CONFLICT',
          'Project version is stale',
          { projectId: id, expectedVersion },
        )
      }
      return deleteProjectResultSchema.parse({
        id,
        name: current.name,
        deletedAt,
      })
    })
  } catch (error) {
    if (error instanceof DomainError) throw error
    throw new DomainError(
      'PROJECT_DELETE_FAILED',
      'Project deletion failed',
      { projectId: id },
    )
  }
}
```

Keep table names in the module-level readonly tuple shown above rather than accepting user input. SQLite foreign keys already cascade project-owned rows and set `activities.project_id` to `NULL`, so this plan does not add a migration.

const removeProjectRows = <Value>(
  rows: Value[],
  belongsToProject: (value: Value) => boolean,
) => {
  for (let index = rows.length - 1; index >= 0; index -= 1) {
    if (belongsToProject(rows[index]!)) rows.splice(index, 1)
  }
}

async deleteProject(projectId, version) {
  const index = projectState.findIndex(({ id }) => id === projectId)
  const project = projectState[index]
  if (!project) throw new Error(`Project not found: ${projectId}`)
  if (project.version !== version) throw new Error('Project version is stale')
  projectState.splice(index, 1)
  removeProjectRows(memberState, (item) => item.projectId === projectId)
  removeProjectRows(taskState, (item) => item.projectId === projectId)
  removeProjectRows(requirementState, (item) => item.projectId === projectId)
  removeProjectRows(defectState, (item) => item.projectId === projectId)
  removeProjectRows(sessionState, (item) => item.projectId === projectId)
  removeProjectRows(handoffState, (item) => item.projectId === projectId)
  removeProjectRows(deliverableState, (item) => item.projectId === projectId)
  return {
    id: project.id,
    name: project.name,
    deletedAt: new Date().toISOString(),
  }
}
