# Project OS 任务管理视觉原型设计

## 目标

制作一个可离线打开的单文件 HTML 原型，用于验证 Project OS 前端是否适合参考图所呈现的“电影感玻璃控制台”视觉方向。原型聚焦 1440px 桌面端任务管理页，以视觉还原为第一优先级，不接入真实后端，也不修改现有 React 页面。

## 设计原则

- 移植参考图的视觉语言，不照搬 WenXiBuddy 品牌与业务内容。
- 以 Project OS 的现有导航、任务、项目、负责人、需求、缺陷和设置概念组织内容。
- 视觉焦点集中在当前任务、主要操作和进度，荧光绿不作为大面积底色使用。
- 信息密度较高，但通过留白、明暗层级和边缘高光保持可读性。
- 动效只服务于空间感和状态反馈，并尊重 `prefers-reduced-motion`。

## 页面结构

页面采用三栏桌面布局：

1. 左侧 220px 品牌导航栏：Project OS 标识、主导航、当前工作区和本地负责人。
2. 中央弹性工作区：标题与搜索、四张任务指标卡、任务看板与 3D 卡片组、底部项目时间线。
3. 右侧约 300px 智能详情栏：当前任务摘要、负责人、项目、截止时间、状态、优先级、标签、AI 建议和操作按钮。

主工作区的第一屏必须同时看见关键指标、主要任务区域、智能详情与时间线开头，从而保持参考图的“控制台全景”感觉。

## 视觉系统

- 背景：近黑色底面，叠加低对比网格、顶部柔光和局部绿色环境光。
- 表面：烟灰色半透明玻璃，细银色边框，顶部或斜向高光，轻微背景模糊。
- 强调色：荧光绿用于选中态、主要按钮、活动状态、进度和时间线焦点。
- 状态色：红色表示逾期或高风险，琥珀色表示中等优先级，蓝紫色只用于次级分类。
- 字体：优先使用系统中文无衬线字体；数字使用等宽特征，增强仪表盘感。
- 圆角：主面板约 18px，普通卡片约 14px，标签和按钮使用胶囊圆角。
- 阴影：以黑色深阴影建立层次，以低透明白色内高光模拟金属和玻璃边缘。

## 核心组件

### 顶部工具区

包含页面标题、副标题、全局搜索、通知入口和“新增任务”主按钮。搜索框保持窄长、低对比，主按钮使用深色玻璃与绿色边缘光，而非纯绿色填充。

### 指标卡

展示今日待办、进行中、已完成和逾期任务。每张卡包含标签、大号数字、趋势和小型线性图形或图标。逾期卡只在数字与状态标记上使用红色。

### 任务看板与 3D 卡片组

左侧保留可扫描的分组任务列表；右侧使用一组透视排列的玻璃任务卡形成视觉主景。当前任务卡采用绿色半透明表面，其他卡片使用银灰玻璃。任务卡随指针产生非常轻微的视差和高光移动，但不影响点击区域。

### 智能详情栏

详情栏固定在右侧，以更高的玻璃亮度与边缘高光形成独立层级。点击任务后，标题、编号、负责人、状态、进度和建议内容同步更新。主要操作为“完成任务”，次要操作为“编辑任务”。

### 项目时间线

位于主工作区底部，以水平条展示不同任务阶段。当前日期用荧光绿竖线标记，进行中任务使用绿色渐变，其他任务使用银灰色。

## 交互与状态

- 点击任务列表或 3D 卡片会更新选中态与右侧详情。
- 看板范围标签可在全部任务、我负责的、我参与的之间切换，并更新可见任务数量。
- 时间范围按钮可切换时间线展示密度。
- “新增任务”“编辑任务”“完成任务”在原型中提供明确的点击反馈；不写入持久数据。
- 键盘可聚焦主要导航、筛选和任务项；焦点样式使用绿色外环。
- 系统偏好减少动效时，关闭视差、浮动和连续光效，仅保留瞬时状态变化。

## 数据与边界

原型使用内嵌的中文演示数据和本地脚本，不调用 API、不依赖外部字体或图片。所有演示数据只存在于当前页面内存，刷新后恢复初始状态。

交付文件位于 `docs/prototypes/project-os-task-console.html`。本轮不修改 `web/src` 下的 React 组件、样式、测试或生产构建配置。

## 验收标准

- 双击 HTML 文件即可在现代浏览器中完整打开，无需开发服务器或网络连接。
- 1440px 宽度下三栏布局完整，首屏可见指标区、任务主景、智能详情与时间线。
- 视觉上清晰体现近黑背景、烟灰玻璃、银色高光边缘、荧光绿焦点与空间层叠。
- 至少支持任务选择、范围标签切换、时间范围切换和主要按钮反馈。
- 在启用减少动效偏好时，不出现连续视差或漂移动画。
- 不覆盖或改动工作区中已有的前端开发文件。
