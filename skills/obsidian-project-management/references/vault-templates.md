# Vault templates

Use these templates from the Vault instead of inventing alternative fields:

- Project: `E:\obsidian_warehouse\软件开发\模板\项目模板\`
- Task: `E:\obsidian_warehouse\软件开发\模板\任务模板.md`
- Handoff: `E:\obsidian_warehouse\软件开发\模板\handoff模板.md`
- Data collection: `E:\obsidian_warehouse\每日数据抓取\模板\`

Required task frontmatter fields are `id`, `项目`, `状态`, `负责人`, `优先级`, `依赖`, `关联SPEC`, and `最后更新`.

Allowed task states are `待开始`, `进行中`, `受阻`, and `已完成`. Preserve the headings `目标与 SPEC 对齐`, `实施计划`, `进度记录`, `验收`, `阻塞与风险`, `下一步`, and `关联 handoff`.

Handoff files must state completed work, unfinished work and next step, verification evidence, risks, and SPEC deviations. Write `无` explicitly when there is no deviation.
